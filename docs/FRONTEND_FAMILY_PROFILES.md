# Семейные профили — что сделать на фронте

Только этот сценарий: тап по профилю → **главная от имени этого человека**, не редактирование.

Base: `http://85.198.101.179:8007`  
Auth: `Authorization: Bearer <access>`

---

## Зачем

Мама ведёт историю ребёнка. Взрослый — родителей.  
Тап по «Мама» / «Сын» в карусели = **войти как этот человек** (home), не экран «Редактировать».

---

## Этап 1. Список профилей (карусель)

**GET** `/api/me/profiles/`

В ответе карточки: `id`, `label`, `is_owner`, `is_active`, имя и т.д.

- Рисуете карусель как сейчас.
- Запомните `id` выбранного профиля.

---

## Этап 2. Тап по карточке = ВОЙТИ (не редактировать)

При тапе по аватару/карточке в карусели:

1. Вызвать:

```http
POST /api/me/profiles/{id}/activate/
```

Тело не нужно (пустой POST).

2. Пример ответа:

```json
{
  "open": "home",
  "active_profile_id": 42,
  "profile": {
    "id": 42,
    "label": "Мама",
    "is_active": true,
    "first_name": "Тест88",
    "last_name": "ннгг"
  }
}
```

3. Если `open === "home"`:
   - сохранить локально `active_profile_id` (и при желании весь `profile`);
   - **сразу открыть главную** (Home / таб «Главная»);
   - в шапке/карусели показать, что активен этот профиль (`is_active` / ваш стейт).

**Нельзя:** на тап открывать `GET /api/me/profiles/{id}/` или экран с кнопкой «Редактировать».

---

## Этап 3. Редактирование — отдельная кнопка

Только карандаш / кнопка «Редактировать»:

| Действие | Запрос |
|----------|--------|
| Посмотреть карточку | `GET /api/me/profiles/{id}/` |
| Сохранить | `PATCH /api/me/profiles/{id}/` |
| Удалить доп. профиль | `DELETE /api/me/profiles/{id}/` |

Владельца (себя) обычно не удаляют.

---

## Этап 4. После activate — история и помощник

Активный профиль хранится на бэке (`active_profile_id`).

Проверка: **GET** `/api/auth/me/` → поле `active_profile_id`.

Дальше:

- **История болезней** `POST /api/me/disease-records/`  
  - можно **не** слать `subject_user_id` — бэкенд возьмёт активный профиль;  
  - или явно слать `subject_user_id: active_profile_id`.
- **Список записей** — тоже в контексте активного (если API принимает `subject_user_id` — передавайте его).
- **Помощник** — при необходимости тот же `subject_user_id`.

На главной/в истории должно быть видно: «сейчас: Мама» / «Сын».

---

## Этап 5. Вернуться к себе (владелец)

Тап по **своему** профилю в карусели → снова:

```http
POST /api/me/profiles/{owner_id}/activate/
```

→ `open: "home"` → главная уже от имени владельца.

---

## Чеклист приёмки

- [ ] Тап «Мама» → **Home**, не экран редактирования  
- [ ] Карандаш → редактирование  
- [ ] После activate новая запись истории уходит на этого человека  
- [ ] Тап по себе → снова свой Home  
- [ ] После перезапуска приложения `GET /api/auth/me/` → тот же `active_profile_id` (если не сбрасывали)

## Кратко

| UI | API | Куда вести |
|----|-----|------------|
| Тап по профилю в карусели | `POST .../profiles/{id}/activate/` | **Главная** |
| Карандаш / «Редактировать» | `GET` / `PATCH .../profiles/{id}/` | Экран редактирования |
| Кто сейчас активен | `GET /api/auth/me/` → `active_profile_id` | Бейдж / карусель |
