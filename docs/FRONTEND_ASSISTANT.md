# Помощник: симптомы руки ≠ боль в горле

## Что сломалось

На экране выбрано:

- симптомы: боль в мышцах / плече / руке / суставах, онемение конечностей
- уточнение: локоть, указательный палец
- часть тела: **Правая рука**

«Возможные состояния» показали **горло / грудь / лицо**.

Текст «Ниже — возможные варианты из справочника…» = **не ответ модели**, а fallback справочника.  
Поиск шёл по слову **«боль»** → первые в алфавите: «Атипичная лицевая боль», «Боль в горле», «Боль в груди».

RuTronix тут ни при чём: либо таймаут ИИ, либо пустой ключ — тогда берётся каталог. Каталог искал слишком широко.

## Что сделано на бэке

1. Слово «боль» **больше не ищется отдельно**.
2. Учитывается **часть тела** (`body_parts` / «Правая рука»).
3. Заболевания другой области (горло, грудь, лицо…) отбрасываются.
4. Если ИИ всё же вернул «боль в горле» при руке — бэкенд это вычищает.

## FE: ничего не выдумывать

`POST /api/assistant/diagnose/` (как сейчас):

```json
{
  "symptoms": [id, id],
  "symptoms_text": "болит локоть, затекает указательный палец",
  "body_parts": [id],
  "temperature_c": null,
  "blood_pressure": ""
}
```

Показывать:

- `possible_conditions` — список строк
- `body_parts_resolved` — чтобы в карточке было «Часть тела: Правая рука»
- `answer` / `disclaimer`

Не подменять результат локальным поиском по «боль».

## Проверка

Те же параметры, что на скрине → в «Возможные состояния» не должно быть «Боль в горле / груди / лицевая боль». Ожидаются варианты про руку, плечо, локоть, суставы, онемение.
