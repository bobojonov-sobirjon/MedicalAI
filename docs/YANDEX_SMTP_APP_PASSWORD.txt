Как получить пароль приложения Яндекс для SMTP
==============================================

Обычный пароль от Яндекс ID в SMTP не подойдёт.
Нужен отдельный пароль приложения (тип «Почта»).


Шаг 1. Включить доступ для почтовых программ
--------------------------------------------

1. Войдите в Яндекс Почту:
   https://mail.yandex.ru

2. Откройте раздел «Почтовые программы»:
   https://mail.yandex.ru/?dpda=yes#setup/client

3. В блоке «Разрешить доступ к почтовому ящику с помощью почтовых клиентов»
   включите:
   - С сервера imap.yandex.ru по протоколу IMAP
   - Пароли приложений и OAuth-токены

4. Нажмите «Сохранить».


Шаг 2. Создать пароль приложения
--------------------------------

1. Откройте страницу паролей приложений:
   https://id.yandex.ru/security/app-passwords

   Или: Яндекс ID → Безопасность → Доступ к вашим данным → Пароли приложений

2. В блоке «Создать пароль приложения» нажмите «+» напротив «Почта».

3. Введите название, например: MedicalAI SMTP

4. Нажмите «Далее».

5. Сразу скопируйте пароль — он показывается только один раз.
   Если окно закрыли, этот пароль уже не увидеть: удалите его и создайте новый.

Яндекс пишет, что новый пароль может начать работать через 2–3 часа.


Шаг 3. Параметры SMTP
---------------------

Сервер:   smtp.yandex.ru
Порт:     587 (STARTTLS) или 465 (SSL)
Логин:    полный адрес, например you@yandex.ru
Пароль:   пароль приложения, не обычный пароль аккаунта


Для .env этого бэкенда (порт 587)
---------------------------------

В проекте уже стоит EMAIL_PORT=587 и EMAIL_USE_TLS=true:

EMAIL_HOST=smtp.yandex.ru
EMAIL_PORT=587
EMAIL_USE_TLS=true
EMAIL_HOST_USER=you@yandex.ru
EMAIL_HOST_PASSWORD=xxxx-xxxx-xxxx-xxxx
DEFAULT_FROM_EMAIL=you@yandex.ru

Строку EMAIL_BACKEND=django.core.mail.backends.console.EmailBackend
уберите — иначе письма не уйдут через реальный SMTP.


Важно
-----

- Пароль приложения не кладите в чат, git и .env.example.
- Если аккаунт восстановили или нажали «Выйти на всех устройствах»,
  все пароли приложений сбрасываются — нужно создать заново.
